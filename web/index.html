Live dashboards

The same two cards that are PNG-like in the profile README, but here they accept input: hover a day in the terrain to lift it, hover a bar in the dashboard to read the exact number, and switch themes. Everything is drawn from data/stats.json — the same file the generated SVGs come from, so the numbers cannot disagree.

▶ Play the contribution snake README kiranreddy.nl
Signal dashboard hover a bar
Point at a column to read the exact hour and count.
Contribution terrain hover a block
Point at a block to read its date and count.

On github.com these are <img> tags served through Camo, which delivers no pointer events — that is why they look like pictures there. This page is the interactive version of the same data, and it runs from any static host (kiranreddy.nl) with no build step.
